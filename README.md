# Saint Scientific Calculator 🧮

A full-stack scientific calculator with history saved to database.

Live Demo: https://calculator-ten-rho-55.vercel.app

## Features
- Scientific functions (sin, cos, tan, √, π, %, etc)
- Calculation history saved to MongoDB
- Responsive design

## Tech Stack
- Frontend: HTML, CSS, JavaScript (Deployed on Vercel)
- Backend: Node.js + Express (Deployed on Render)
- Database: MongoDB Atlas

## How it works
Frontend -> Backend API -> MongoDB
